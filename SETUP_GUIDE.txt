===========================================
TERRA LUXE (TERRAVA) - DEEP SETUP GUIDE
===========================================

Welcome! If you are setting this project up on a completely new PC, follow this step-by-step guide carefully.

-------------------------------------------
STEP 1: INSTALL REQUIRED SOFTWARE
-------------------------------------------
Before touching any code, make sure your new PC has the following installed:

1. **Git**: Download and install from https://git-scm.com/
2. **Node.js**: Download and install v18 or v20 LTS from https://nodejs.org/
3. **Java Development Kit (JDK 17)**: Download and install JDK 17 (e.g., from Oracle or Adoptium).
4. **Apache Maven**: Download and set up Maven (https://maven.apache.org/download.cgi). Ensure `mvn` is in your system PATH.
5. **MySQL Server**: Download and install MySQL (v8.0+). Set the root password to `@Root` (or remember what you set it to).
6. **Ganache**: Download and install the Ganache GUI for local blockchain testing from https://trufflesuite.com/ganache/

-------------------------------------------
STEP 2: CLONE THE PROJECT
-------------------------------------------
1. Open a terminal (or Git Bash / Command Prompt).
2. Clone the repository from GitHub:
   git clone https://github.com/Ritikjagtap11/Terrava.git
3. Enter the project folder:
   cd Terrava

-------------------------------------------
STEP 3: BLOCKCHAIN SETUP (Ganache & Truffle)
-------------------------------------------
1. Open your **Ganache** application and click "Quickstart" to start a local Ethereum workspace. It should run on `http://127.0.0.1:7545` or `9545`. 
2. Open a new terminal inside the `Terrava/blockchain/` folder.
3. Install Truffle globally (if you haven't already):
   npm install -g truffle
4. Install local blockchain dependencies:
   npm install
5. Compile the smart contracts:
   truffle compile
6. Deploy the contracts to your Ganache local blockchain:
   truffle migrate --reset
7. Look at the terminal output and **COPY the contract address** of `AgriSupplyChain`. You will need this for the backend.
8. In Ganache, click on the key icon next to the first account (Index 0) and **COPY the Private Key**.

-------------------------------------------
STEP 4: DATABASE SETUP (MySQL)
-------------------------------------------
1. Open your MySQL Command Line Client or MySQL Workbench.
2. Log in with your root user and password.
3. Create the database by running this SQL command:
   CREATE DATABASE agrotrust;
   (The Spring Boot backend will automatically create all the necessary tables when it starts.)

-------------------------------------------
STEP 5: BACKEND SETUP (Spring Boot)
-------------------------------------------
1. Navigate to the `Terrava/backend/src/main/resources/` folder.
2. Open `application.properties` in a text editor.
3. Update the following fields:
   - `ethereum.contract.address`: Paste the Contract Address you copied in Step 3.
   - `ethereum.private.key`: Paste the Ganache Private Key you copied in Step 3.
   - `spring.datasource.password`: Put your MySQL root password (e.g., `@Root`).
4. Open a terminal inside the `Terrava/backend/` folder.
5. Clean and build the Java application:
   mvn clean install
6. Run the backend server:
   mvn spring-boot:run
   (Wait until you see "Started AgrichainApplication". It runs on http://localhost:8080)

-------------------------------------------
STEP 6: FRONTEND SETUP (React + Vite)
-------------------------------------------
1. Open a new terminal inside the `Terrava/frontend/` folder.
2. Install the frontend dependencies:
   npm install
3. Start the Vite development server:
   npm run dev
4. The terminal will give you a local URL (usually http://localhost:5173 or http://localhost:3000). Open this in your browser!

-------------------------------------------
STEP 7: HOW TO VERIFY BLOCKS & TRANSACTIONS ON GANACHE
-------------------------------------------
To verify that the blockchain logic is actually working whenever you register a product or create an order:

1. **Using Ganache GUI**:
   - Keep the Ganache application open while using the web app.
   - Go to the Terrava website, log in as a Farmer, and "Register a Product".
   - Switch back to Ganache and click the **"Blocks"** tab. You should see a brand new block just mined!
   - Click the **"Transactions"** tab. You will see a new transaction hash. Click on it to see the gas used, sender address, and the encoded data sent to the smart contract.

2. **Using Ganache CLI / Truffle**:
   - In the `blockchain/` folder terminal, run: `truffle console --network development`
   - Type: `await web3.eth.getBlockNumber()` (This will show the current block count).
   - Register a product on the website.
   - Type: `await web3.eth.getBlockNumber()` again. The number will have increased by 1!
